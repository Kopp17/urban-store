## ✨ Aperçu

Urban Store est une boutique en ligne moderne et responsive avec des fonctionnalités avancées pour une expérience d'achat optimale.

![Urban Store Preview](https://via.placeholder.com/800x400?text=Urban+Store+Preview)

## 🚀 Fonctionnalités

### Pour les clients
- ✅ Interface moderne et responsive
- ✅ Recherche en temps réel
- ✅ Filtrage par catégories
- ✅ Tri des produits (prix, nom)
- ✅ Panier persistant (localStorage)
- ✅ Gestion des quantités
- ✅ Commande via WhatsApp intégrée
- ✅ Newsletter
- ✅ Design premium avec animations

### Technologies
- HTML5 sémantique
- CSS3 moderne (Grid, Flexbox, Variables CSS)
- JavaScript ES6+
- Font Awesome 6
- Google Fonts (Poppins)
- LocalStorage API
- WhatsApp API
